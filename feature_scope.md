# Feature Scope

## Must have

- Citizen waste image upload.
- YOLO detection.
- CLIP fallback.
- Waste category normalization.
- Disposal guidance.
- Pickup request creation.
- Request tracking.
- Admin dashboard.
- Map with requests.
- Priority score.
- DBSCAN clustering.
- OR-Tools route optimization.
- Vehicle capacity.
- Route comparison metric.
- Deterministic seed data.

## Should have

- Request filters.
- Route stop details.
- Basic collection statistics.
- Pickup status updates.
- Explainable priority reasons.

## Stretch only

- Waste hotspot heatmap.
- Demand prediction with XGBoost.
- Smart-bin simulation.
- Citizen eco-score.
- Voice input.
- LLM assistant for non-critical explanations.

## Explicitly out of scope

- Real-time municipal integrations.
- Real ambulance/vehicle GPS tracking.
- IoT sensor ingestion.
- Payment processing.
- Social login.
- Full production RBAC.
- Live traffic routing.
- Automated municipal policy/legal advice.
- Medical/hazardous-waste treatment advice beyond deterministic informational guidance.
