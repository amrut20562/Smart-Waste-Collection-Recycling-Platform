# Technical Sources

The following official/current documentation should be treated as the source of truth for integration details:

- Ultralytics YOLO documentation: https://docs.ultralytics.com/ — model families and Python inference APIs.
- Hugging Face Transformers CLIP documentation: https://huggingface.co/docs/transformers/model_doc/clip — CLIP image/text embeddings and zero-shot usage.
- Hugging Face pipeline documentation: https://huggingface.co/docs/transformers/main/main_classes/pipelines — `zero-shot-image-classification` pipeline and candidate labels.
- Google OR-Tools: https://developers.google.com/optimization/routing — vehicle routing, capacity/time constraints, and routing concepts.
- Google OR-Tools routing tasks: https://developers.google.com/optimization/routing/routing_tasks — solver/search/time-limit guidance.
- scikit-learn DBSCAN: https://scikit-learn.org/stable/modules/generated/sklearn.cluster.DBSCAN.html — clustering API and parameter behavior.
- FastAPI documentation: https://fastapi.tiangolo.com/ — backend framework and request/file handling.
- React documentation: https://react.dev/ — frontend framework.
- Leaflet documentation: https://leafletjs.com/ — interactive maps.
